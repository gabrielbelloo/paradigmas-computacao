# Vaga: Engenheiro de Software Sênior

**Empresa:** Nubank

**Local:** São Paulo – SP

## Descrição

Buscamos as melhores práticas de desenvolvimento de software, que atualmente incluem uma variedade de tecnologias. Embora valorizemos candidatos familiarizados com elas, também temos certeza de que os engenheiros de software interessados em ingressar no Nubank poderão aprender com nossa equipe.

### Tecnologias utilizadas

- Microsserviços horizontalmente escaláveis escritos principalmente em **Clojure**
- Framework **Finagle**
- Programação Funcional
- Arquitetura Hexagonal
- Kafka para comunicação entre serviços
- Integração e Deploy Contínuo (CI/CD)
- AWS
- Datomic
- DynamoDB
- Prometheus
- Kubernetes

### Modelo de Trabalho

**Híbrido (2 a 3 vezes por semana)**

O modelo híbrido do Nubank prevê a presença no escritório pelo menos duas vezes por semana, em dias estratégicos definidos para maximizar a conexão e a colaboração entre as equipes.
